# CLAUED-1

## APMAC — القانون الأساسي (statutes presentation)

An animated, Arabic-first web presentation of the statutes of «الجمعية المهنية المغربية للفنانين الممثلين – سوس ماسة» (APMAC).

```bash
cd apmac-presentation
npm install
npm run build && npm run preview   # open http://localhost:4173 and press F
```
