# MACHRI — 4-in-1 car emergency device · vertical ad (Remotion)

1080×1920 · 30 fps · 23.6 s · H.264. Moroccan Darija voice-over (ElevenLabs) is the master timeline.

## Layout

```
timeline.json              single source of truth: verified speech frames, edit decision list, captions, CTA
public/media/              source_footage.mp4 (supplied), voiceover.mp3 (supplied, played untouched)
public/fonts/              Cairo variable (wght 200–1000), Arabic + Latin subsets, bundled locally
public/clips/              per-shot clips generated by scripts/prepare_footage.py (git-ignored)
src/
  MachriAd.tsx             composition: shots → grid → captions → brand → CTA, voice-over audio
  components/Footage.tsx   shot layer: push-in camera, problem/solution grade, settle/wipe entries,
                           progressive blur that hides the baked-in English caption in source S2
  components/TextLockup.tsx  Arabic kinetic typography (masked word reveals, RTL, accent keywords)
  components/FourGrid.tsx  "4 خدمات" grid of the four real demos; power tile expands into the next shot
  components/Brand.tsx     MACHRI wordmark bug + CTA end card
  theme.ts / fonts.ts / timeline.ts   design tokens, font loading, typed timeline
scripts/
  analyze_audio.py         waveform segmentation + Whisper word onsets snapped to energy dips → data/audio_analysis.json
  prepare_footage.py       trims/crops/retimes (motion-interpolated)/upscales clips, no audio track
  qa.py                    checks the rendered MP4 and writes the contact sheet + data/qa_report.json
data/                      ASR words, audio analysis, waveform image, QA report
```

## Commands

```bash
npm install
npm run prepare-footage            # builds public/clips/*.mp4 from timeline.json (needs ffmpeg)
npm run studio                     # preview / edit in Remotion Studio
npm run render                     # → out/MACHRI_AD_FINAL.mp4
python3 scripts/qa.py              # → out/MACHRI_QA_CONTACT_SHEET.png + data/qa_report.json
```

`remotion.config.ts` points Remotion at a pre-installed headless Chromium when one exists
(`/opt/pw-browsers/...`); elsewhere Remotion downloads its own.

## Editing

- Retime a caption: change `at` (reveal frame) / `out` (exit start) in `timeline.json`. Exits take 8 frames;
  keep `out + 8` ≤ the next cut. `speech[].keys` holds the verified word-onset frames to sync against.
- Change a shot: edit its `source` range / `crop` / `clipFrames`, then `python3 scripts/prepare_footage.py --only shXX`.
- Text styling lives in `src/theme.ts`; words wrapped in `*asterisks*` render in the accent colour.
- Arabic rule: animate whole words only and never apply letter-spacing to Arabic (it breaks letter joining).
